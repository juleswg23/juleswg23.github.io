Great Tables & gt-extras: Talk Outline

“Telling Better Data Stories with Beautiful Tables”

Duration: 35 minutes + 5 min Q&A

ACT I: The Hook (5 minutes)

Set the Stage: Tables Don’t Have to Be Boring

Slide: Title Slide - Title: “Great Tables & gt-extras” - Subtitle: “Telling Better Data Stories with Beautiful Tables”

Slide: About You - 📊 gt-extras author, Great Tables contributor - 💡 I enjoy patterns and helping people see patterns - Who am I to tell you about tables? (Personal connection: KenKen puzzle image. emphasize that tables, like puzzles, are a great place to see patterns.)

Slide: The Problem - Show a screenshot of a plain, ugly table (default pandas DataFrame display) - Quote: “They say a picture is worth a thousand words, so why do we have to look at tables with a thousand cells of text?” - The belief we’re challenging: “Tables are boring. Charts tell the real stories.” - Our argument: Tables CAN be beautiful, engaging, AND tell powerful stories

ACT II: The Killer Example (8 minutes)

Starting with Wow: Deconstruct the NFL Example

Slide: Full NFL Table - Show the complete rendered NFL 2011 season table (from current slides) - Take a moment to let it sink in: This is a table, but it’s visually engaging - It tells multiple stories at once

Slide: What Makes It Work? - Strategic use of color (green/yellow/red for point differential) - Embedded visualizations (win/loss streaks, dumbbell plots) - Clear hierarchy and organization (division grouping, team logos) - Responsive styling (Super Bowl winners highlighted) - Professional theme/polish

Slide: This Wasn’t Hand-Coded HTML - This was created with Python + Great Tables + gt-extras - Clean, chainable API (show the method chaining structure without diving into code details yet) - The point: You don’t need to be a web designer to make this

ACT III: Build It Up (14 minutes)

Understanding the Building Blocks

Section: What is Great Tables? (7 minutes)

Slide: Great Tables Foundation - Created by Rich Iannone (originally gt in R) - Now available in Python (maintained by Michael Chow at Posit) - Philosophy: Tables are a first-class visualization medium - Key capabilities: - Organize and present data clearly - Apply professional formatting (numbers, dates, currencies) - Add titles, subtitles, source notes - Style cells, rows, columns - Create polished, publication-ready output

Slide: The Components of a Table - Show the Great Tables component diagram (visual reference from docs) - The building blocks (from top to bottom): - Table Header (optional) - Title and subtitle - Stub & Stub Head (optional) - Row labels and row groups - Column Labels (required) - Column headers, optionally with spanners - Table Body (required) - The data cells - Table Footer (optional) - Source notes and footnotes - Key insight: Think of a table as a composition of parts, not a monolith - The chainable API lets you build these parts together, each method adds clarity

Slide: Building Blocks in Action - The NFL Example - Show how each component appears in the NFL table: - Header: “NFL 2011 Season” title - Stub: Team names, organized by division (row groups) - Column Labels: Score, Wins, Losses, etc. - Body: The data, with embedded visualizations and colors - Footer: Data source attribution - Key insight: Every component serves the story. Nothing is decorative.

Slide: Structuring Your Data - The stub: Grouping rows for context (e.g., by division) - Makes patterns visible without additional explanation - Example: In NFL table, you immediately see which division won the most games - Column organization: Headers and spanners group related columns - Example: Group “Wins/Losses/Ties” under one spanner vs. separating them - Why it matters: Structure guides the reader’s eye and shapes their understanding

Slide: Formatting & Polishing - Format numbers meaningfully: - Decimals (precision matters) - Currency (for financial data) - Percentages (for proportions) - Compact notation (large numbers readable) - Example: In NFL table, points are formatted consistently - Polish with basic styling: - Colors, fonts, alignment—choose intentionally - Every choice should reduce cognitive load, not add distraction - Why it matters: Professional formatting signals “this data is important”

Slide: The Art of Visual Hierarchy - Guide attention with contrast: - Color (most powerful): Use strategically to highlight patterns - Size/weight: Headers bigger/bolder than body - Spacing: Group related items, separate concerns - Strategic use of the full table: - Headers and spanners guide the eye to structure - Stubs create visual anchors - Footer provides context (source, notes) - Example: NFL table uses color on point differential to instantly convey performance - Key insight: Every element works together to tell the story faster

Section: gt-extras - Unlocking Creative Potential (7 minutes)

Slide: What is gt-extras? - Extension package that adds powerful new capabilities to Great Tables - Built on top of the Great Tables foundation (components + formatting + styling) - Philosophy: Use tables for data storytelling, not just data presentation - The question it answers: “What if we could embed visualizations and advanced styling within table cells?” - Organized into 4 main capability areas:

Slide 1: Plotting Functions ⭐ PRIMARY FOCUS - “Put Small Multiples Inside Your Table Cells” - gt_plt_bar() - Embed bar charts in cells (compare magnitudes) - gt_plt_dumbbell() - Compare two values visually (before/after, actual vs. target) - gt_plt_winloss() - Show win/loss/tie records at a glance (seasons, streaks) - gt_plt_bullet() - Show performance against targets (goal tracking) - gt_plt_sparkline() - Trend visualization in cells (time series at a glance) - Why? Numbers alone obscure patterns. Let visualizations live alongside data. - Example from NFL table: Win/loss streaks and dumbbell plots (margin of victory vs. margin of defeat)

Slide 2: Coloring & Highlighting Functions - “Leverage Color as a Data Channel” - gt_color_box() - Heat map style coloring with custom palettes - gt_highlight_cols() / gt_highlight_rows() - Draw attention strategically - gt_add_divider() - Visual separation for emphasis - Why? Color is one of the fastest ways our brains process information - Cognitive science: Humans process color faster than text or even small charts - Example from NFL table: Green/yellow/red for point differential

Slide 3: Theming Functions - “Pre-Built, Professional Aesthetics” - gt_theme_538() - FiveThirtyEight style (data journalism aesthetic) - gt_theme_dot_matrix() - Playful, retro aesthetic - Pre-built themes for instant professionalism - Why? Consistency and polish matter; shouldn’t require hours of CSS - Insight: Great Tables handles the technical details; gt-extras provides the polish

Slide 4: Iconing & Imaging Functions - gt_fa_rank_change() - Font Awesome icons for trends (arrows, up/down, etc.) - fmt_image() - Embed images directly in cells (logos, photos) - Why? Visual elements are faster to parse than text - Example: NFL table uses team logos instead of team name text alone

Slide: The Real Power - Stacking Capabilities - Show the NFL example as a complete picture: - Start with a DataFrame of NFL data - Use Great Tables to structure: grouping by division (stub), organizing columns - Use Great Tables to format: team logos (images), scores (numbers) - Use Great Tables to style: basic colors and fonts - Use gt-extras to elevate: embedded win/loss streaks, dumbbell plots, color boxes - Use gt-extras theming: consistent, professional aesthetic - Each layer adds a dimension to the storytelling - The result: One cohesive, beautiful table that answers multiple questions simultaneously - Key insight: Great Tables is the foundation. gt-extras is the creative power-up.

Key Themes to Weave Throughout

  1. Tables are underrated. They’re often faster to parse than charts.
  2. Beauty and function go together. Polish isn’t frivolous; it signals professionalism and engages your audience.
  3. The tools are accessible. You don’t need to be a designer or web developer.
  4. Storytelling is the goal. Every formatting choice should serve the narrative.

Conceptual Framework

The talk follows a specific philosophy about tables as a medium: 1. Tables have components (not monolith structure) - Great Tables teaches you to think compositionally 2. Each component serves the story - Nothing is decorative; every choice guides understanding 3. Great Tables provides the foundation - Structure, formatting, styling 4. gt-extras adds creative power - Embed visualizations, leverage color, achieve polish 5. The result is data storytelling - Just as effective as (often better than) charts for communicating insights

Use this framework to guide which examples you show and how you present them. Every visual should reinforce: “Look how these components work together to tell a story.”
